BRIDGE MAMAN V5.1
=================
Version basée sur la maquette validée.

Modifications intégrées :
- présentation réaliste avec les 4 joueurs autour de la table ;
- enchères à gauche ;
- contrat, entame, score et historique à droite ;
- barre Revenir / Conseil / Rejouer la donne / Chat ;
- rejouer exactement la dernière donne ;
- carte qui se soulève sous le doigt avant validation ;
- lorsque Sud est le mort, le joueur choisit lui-même sa carte ;
- affichage des couleurs dans l'ordre ♥ Cœur, ♠ Pique, ♦ Carreau, ♣ Trèfle ;
- classement des cartes de la main dans le même ordre ;
- classement officiel des enchères conservé en interne : ♣ ♦ ♥ ♠ SA ;
- nouvelle donne disponible ;
- cache V5.1 pour forcer la mise à jour GitHub Pages.

Pour une présentation fidèle à la maquette, utiliser l'iPhone en mode paysage.
