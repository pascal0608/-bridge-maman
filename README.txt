BRIDGE EXPERT SEF — VERSION IPHONE
===================================

Contenu :
- index.html
- styles.css
- app.js
- manifest.webmanifest
- sw.js

Hébergement gratuit recommandé : GitHub Pages.

Méthode rapide :
1. Créer un dépôt GitHub.
2. Déposer tous les fichiers de ce dossier à la racine du dépôt.
3. Dans GitHub : Settings > Pages.
4. Source : Deploy from a branch.
5. Branch : main / root.
6. Attendre l'adresse publique fournie par GitHub Pages.
7. Ouvrir cette adresse dans Safari sur l'iPhone.
8. Partager > Ajouter à l'écran d'accueil.

La web-app fonctionne ensuite comme une petite application et peut être mise en cache hors ligne.

IMPORTANT
---------
Le moteur de jeu inclus est un moteur d'entraînement "avancé" basé sur des heuristiques
(SEF simplifié pour les enchères, fourniture/prise économique/atout pour le jeu de la carte).
Il ne remplace pas un moteur de niveau championnat/expert humain.
