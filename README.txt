BRIDGE MAMAN V4.1
=================
Version avec vraie présentation "table de bridge" :
- 4 joueurs autour du tapis
- panneau contrat / score
- enchères intégrées à la table
- main de Sud en éventail
- carte qui se soulève sous le doigt avant de jouer
- rejouer la dernière donne
- lorsque Sud est le mort, le joueur choisit lui-même sa carte
